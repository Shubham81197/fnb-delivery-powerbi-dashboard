# F&B Delivery Business Analysis Dashboard 📊

## Project Overview

This is a Power BI project created to analyze a Food & Beverage delivery business.

The project focuses on orders, customers, restaurants, riders, and third-party logistics (3PL) partners.

## Project Objective

The main objective of this project is to understand business performance and use data to identify useful business insights.

### 1. Executive Overview

The Executive Overview includes:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Delivered Orders
- Cancellation Rate
- On-Time Delivery %
- Average Delivery Time

### 2. Customer Analysis

This page focuses on:

- Customer segments
- Orders by city
- Orders by zone
- Customer value
- Customer ordering trends
- Customer ratings

### 3. Delivery & Rider Analysis

This page focuses on:

- Rider performance
- Delivery partner performance
- In-house vs 3PL delivery
- Average delivery time
- On-time delivery
- Delivery distance
- Cancellation reasons

## Business Questions

The dashboard helps answer questions such as:

- Which city generates the most orders?
- Which restaurants generate the highest revenue?
- Which delivery partner performs best?
- What is the average delivery time?
- What is the cancellation rate?
- How do in-house riders compare with 3PL partners?

## Dataset

The dataset used in this project is a simulated dataset created for learning and portfolio purposes.
